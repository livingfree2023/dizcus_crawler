# 验证

```sh
python3 -B -m unittest discover -v
```

HTTP 测试需要绑定本地回环端口；受限环境需授权。没有 pip 依赖。测试目录使用临时文件，结束清理，不修改实际 output/data/config。

## 分层

- 单元/模块：文件名、图片格式边界、URL与路径约束、历史身份、SQLite 双终态及互斥触发器、pending 两个提交中断点、v1 事务迁移及校验损坏拒绝恢复。
- HTTP 模块集成：标准库真实 localhost HTTP server 提供明确标记的中性 classic/X fixtures，经 CLI、真实网络、真实 SQLite、真实文件系统验证板块发现、分页、主楼净化、GIF 字节、重试、二轮零正文请求、GBK、Web 阅读和文件隔离。
- stock 模板回归：活动精华标签与 URL 编码 listextra；无图标普通精华；额外普通列表核验精华置顶；未确认筛选或无法核验置顶时报告失败，不静默成功零条。
- systemd 隔离：真实临时 unit 文件，OS 边界使用测试替身覆盖 systemctl、运行账号和特权所有权修改。验证安装、重装、日程更改、关闭Web、卸载与数据保留；这些测试不代表 Linux 安装已验证。
- 并发与实时诊断：真实localhost HTTP active计数验证并发上限和顺序，覆盖Cookie会话、去重与过滤；独立进程和并发读验证原子进度快照及死亡进程解释。
- 安装权限：在普通测试账号下运行真实只读访问探针，验证读/写/执行/父目录穿行；runuser与fallback边界隔离验证，不回显敏感文件或launcher内容。
- 外部集成：仅使用不含露骨内容的普通论坛做真实探测；记录能访问及不能访问的阶段，不拿 fixtures 充当线上成功。

## 必须保持的回归断言

1. 首次成功后源站改标题、正文和图片，下一轮既不请求该帖正文/媒体，也不改本地文件。
2. 未启用图片门槛时，图片失败或伪装成图片的 HTML 不产生成功记录，后续可重试；启用后继续统计可获取图片，达标只保存成功图片，不足入永久排除历史且无 HTML/pending。
3. 历史数据库丢失/被空库替换时停止，不能重新建立成功历史掩盖问题。
4. 发布前/后的崩溃恢复均只依靠完整本地文件，不创建网络客户端、不覆盖文件。
5. 卸载服务保留配置、HTML 和 SQLite；外来或符号链接 unit 不修改。
6. 列表点击返回原始归档字节；路径穿越无法访问配置或历史。
7. 已归档HTML移走后抓取与--check正常退出，missing_files仅为信息，历史不变且没有正文/媒体请求；Web返回明确404后首页/诊断仍可用。
8. 永久排除后源站修复或调低阈值仍不请求正文/媒体；Web 列表不展示排除项，诊断与本地检查计数可见。
9. GIF 多帧只算一图，同源重复不增计数；坏 URL、403/404/伪图片与占位图不能误增计数或中断其它可获取图片的处理。
