# WorkingDirectory语法修复

真实Ubuntu systemd-analyze verify确认：WorkingDirectory的双引号会成为路径内容，导致非绝对路径错误。该单值路径指令不能复用ExecStart的word quoting。

使用不加外层引号的绝对路径，空格、反斜杠与双引号转义为C风格十六进制，百分号转义%%。控制字符仍拒绝。ExecStart参数继续使用unit_quote。真实服务器临时校验已验证普通路径与带空格/百分号路径均退出0，不修改系统服务。

安装校验失败保留有限长度的实际错误细节，避免泛化错误掩盖原因。测试覆盖路径序列化与失败细节，随后在目标机验证真实安装和阅读服务状态；不通过抓取外部帖子检验服务。
